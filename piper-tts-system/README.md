# Piper-TTS System for TheaterTime

This may eventually get moved into the main project, but for now - it handles to the audio system for TTS.

There is a custom build of piper-tts included - it has a cut down list of voices, those that are included in the binary.

## Build

Run `yarn`, then `yarn run build`.  It builds destructively to the rest of the project.  If you are not making changes to the audio system, no need to build this, the built files are included in the main repo.
